رمزُ الوصول إلى جِتهَب

تحتاجُ اللوحةُ رمزاً يسمحُ بالكتابةِ في مستودع haydarvsky/articles ليُنشَرَ التعديلُ مباشرةً. يُحفظُ الرمزُ في متصفّحِك وحده ولا يُرسَلُ إلى أيِّ جهةٍ غيرِ جِتهَب.

  1. افتحْ إنشاءَ رمزٍ دقيق (Fine-grained).
  2. في Repository access اختر Only select repositories ثم articles.
  3. في Permissions → Repository اجعلْ Contents = Read and write.
  4. أنشئِ الرمزَ وانسخْه والصقْه هنا.
